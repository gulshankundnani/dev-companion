# Decisions, trade-offs, systems and risk playbook

## Compare options
1. Goal and hard constraints (must-haves eliminate options early).
2. 3-6 criteria with weights the user agrees with (cost, effort, risk, performance, maintainability, time).
3. Score each option with evidence, not impressions; note unknowns.
4. Sensitivity: does the winner change if a weight or score moves a little?
5. Recommend one, with the main trade-off and when to revisit.

## Systems thinking
Map components, flows and feedback loops (reinforcing / balancing), delays and bottlenecks; look for second-order effects of a change.

## Risk
List risks as likelihood x impact; mitigation and owner for the top ones; what early signal shows a risk is happening.

## Report
Decision table, recommendation, key assumptions, what would change the answer.
